# Test Outputs & Validation Samples

This directory contains sample outputs captured while developing and validating
ApexView's analysis components. They are retained as a record of the testing and
verification carried out during development — demonstrating how individual
features (pace analysis, tyre-degradation modelling, pit-stop and team-performance
calculations) were exercised and checked against expected behaviour.

These are illustrative artifacts, not part of the production data path. The
project's formal validation lives in `diagnostics/` (the granularity and G0
evidence base) and `tools/ab_harness/` (the regression harness and deviations
registry).
